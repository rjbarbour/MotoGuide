## Description

Outcome: Refactor RideHorizon through independently reviewable child tasks. This milestone is a programme and replenishment gate, not blanket authority to execute every task. RH-013 coordinates the programme. Each child uses one branch, one worktree and one pull request; only ready-labelled tasks may be claimed; reviewed tasks merge serially with a health gate before ready-queue replenishment.

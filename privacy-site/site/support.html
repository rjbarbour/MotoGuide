RideHorizon Support

Help for the iPhone private beta.

Contact

Email privacy@digitalmercenaries.ai. Include the app version and build shown in RideHorizon, your iPhone and iOS version, and what happened. Do not include precise ride locations, credentials or API keys.

Safety

Set up and change RideHorizon only while stopped. Do not interact with the phone while moving. Stop using the app if it becomes distracting or interferes with navigation or audio.

Before reporting a problem

  • Confirm that you tapped Start ride.
  • Confirm location permission and mobile data are available.
  • For Premium Voice, confirm that optional AI features are enabled.
  • When safely stopped, export Release diagnostics from Settings > Advanced if requested.

# Beta App Description

RideHorizon is an iPhone audio place-awareness companion for motorcyclists. It uses location changes to announce nearby towns, counties and regions through the device speaker or a Bluetooth helmet headset. Testers can choose names-only announcements, optional AI-generated short or long place facts, Apple Voice or Premium Voice. RideHorizon runs alongside the tester's normal navigation app; it does not provide routes, safety instructions or emergency guidance. This private beta is focused on real-ride reliability, background location, Bluetooth audio, announcement usefulness and distraction risk.

# What to Test

The most useful test is one normal ride with RideHorizon running alongside your usual navigation and audio. You do not need to test every setting.

Safety:

- Complete setup and change settings only while stopped.
- Keep your normal navigation and riding judgement in charge. RideHorizon is not navigation, safety or emergency software.
- Stop using the app if an announcement is distracting or behaves unexpectedly.

Before riding:

- Complete onboarding and choose whether to allow the optional AI features. No account, invite code or credential is required.
- While stationary, try Test Mode under Settings > Advanced > Developer. Tap Start ride and advance through the Gloucestershire sample locations.
- Check Names Only and Short Facts with Apple Voice and Premium Voice. If useful, also try Long Facts and Quiet Mode.

During a normal ride:

- Check that place announcements are relevant, timely and not repeated unnecessarily.
- Lock the screen or put your navigation app in the foreground and check that an active ride continues.
- If available, use your normal Bluetooth helmet headset and play music or navigation prompts. Check that announcements remain intelligible and that other audio resumes at a comfortable level.
- Pass through an area of weak mobile data if that occurs naturally. Check that late or stale announcements do not play after the place has changed.
- Tap End ride when safely stopped and check that RideHorizon no longer tracks or affects other audio.

Please report:

- Missing, late, repeated or incorrect place announcements or facts.
- Music, navigation or Bluetooth audio conflicts, especially sudden volume changes.
- Crashes, excessive battery use, phone heat or continued background activity after End ride.
- Anything confusing, irritating or distracting, and whether you would use RideHorizon again.

If a problem occurs, note the approximate time and what the phone was doing. While stopped, you can also export the privacy-safe log from Settings > Advanced > Release diagnostics.

# Review Notes

RideHorizon is an iPhone audio place-awareness companion for motorcyclists. It is not a navigation, safety, emergency or vehicle-control app. Review can be completed while stationary; no motorcycle, journey, account, invite code, proxy token, API credential or Bluetooth hardware is required.

To test the optional AI features and sample route:

1. Launch RideHorizon and complete onboarding while stationary.
2. Choose Allow AI features if you wish to test Short Facts, Long Facts or Premium Voice. Choosing Use on-device features only keeps Names Only and Apple Voice available without sending information to the RideHorizon proxy.
3. Open Settings > Advanced > Developer and enable Test Mode. Test Mode is off by default in this Release build.
4. Return to the Location screen and tap Start ride.
5. Tap Next test location to advance through the Gloucestershire sample locations. This triggers representative place changes and announcements without travelling.
6. Try Names Only or Short Facts with Apple Voice and Premium Voice. The iPhone speaker is sufficient.
7. Tap End ride when finished.

To test live location instead, leave Test Mode off, tap Start ride and respond to the location-permission request. RideHorizon uses background location only during an active ride so announcements can continue when the screen is locked or another app is in the foreground.

Optional AI access is provisioned automatically when a consented proxy-backed feature first needs it. Apple Voice remains available when AI sharing is declined or when Premium Voice is unavailable. The production proxy and provider services will remain online during review.
